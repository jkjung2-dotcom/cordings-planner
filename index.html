Google 로그인은 Firebase 인증 승인 도메인 설정이 완료되어야 정상 작동합니다. 로그인 전에는 기존처럼 이 기기에만 저장됩니다. 로그인 후에는 같은 Google 계정의 데이터가 자동으로 동기화됩니다.

최초 1회 Firebase 설정 (프로젝트 관리자)

Firebase 콘솔 → 프로젝트 생성 → 웹 앱 등록 → SDK 설정의 firebaseConfig 객체를 복사해 아래에 붙여넣으세요. 이 설정은 기기의 브라우저에 저장됩니다. 서비스 계정 비밀키나 관리자 키는 절대 넣지 마세요.

PC와 스마트폰에서 동일한 Firebase 프로젝트를 설정하거나, 이 파일에 프로젝트 설정을 내장해 동일한 HTTPS 주소로 배포하세요. Google 인증 승인 도메인과 실제 웹 주소가 일치해야 합니다.

⚠ 동일 계정에서 여러 기기를 동시에 수정하면 마지막으로 저장한 전체 데이터가 우선합니다. 첫 로그인 시 기존 로컬 자료가 클라우드 자료를 자동으로 덮어쓰지 않으며, 업로드 버튼으로 명시적으로 선택할 수 있습니다. 운송장번호 등 개인정보를 공용 기기에서 저장하지 마세요.

5. 택배 추적 · 배송 기록

운송장번호와 택배사를 등록하고 공식 조회 페이지를 열 수 있습니다. 현재 버전은 실시간 자동 추적이 아니라 공식 사이트 연결 + 상태 수동 기록 방식입니다. 묶음 주문이 여러 상자로 나뉘어 배송되어도 각각 등록할 수 있습니다.

조회 페이지에서 운송장번호를 붙여넣으세요. 택배사 미확인 시 Global-e 또는 Cordings 출고 메일에서 운송사를 확인한 뒤 선택하세요. 공식 사이트의 실제 배송 상태가 이 파일에 자동 반영되지는 않습니다.

6. 데이터 보관

로그인 전에는 인터넷 없이 로컬 저장이 가능하고, Firebase 로그인 후에는 인터넷 연결 시 기기 간 자동 동기화됩니다. 오프라인 변경은 로컬에 저장되며 재접속 시 동기화될 수 있으므로 다른 기기와 동시 수정은 피하세요. JSON 백업은 별도로 보관하세요. 이 프로그램은 결제·실시간 상품 검색·관세청 조회 기능이 없는 개인 계획용 계산기입니다. 배송 추적은 운송장 기록과 공식 택배사 조회 페이지 연결 방식이며 자동 배송상태 수집은 지원하지 않습니다.
